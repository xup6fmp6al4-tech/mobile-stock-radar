# Mobile Stock Radar v0.9

手機 PWA + Node/Express 後端。

## API
- `/health`
- `/api/radar`
- `/api/all`

## Render
Build command: `npm install`
Start command: `npm start`

部署成功後先測試：
`https://你的網址.onrender.com/health`
再測試：
`https://你的網址.onrender.com/api/radar`

> Yahoo 公開行情端點可能有延遲、限流或欄位變動；交易前仍需以券商即時行情確認。
